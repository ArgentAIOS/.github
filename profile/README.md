## ArgentOS Core is dropping later today.

We've been building this in private for months. Today -- March 28th, 2026 -- the Core goes public.

ArgentOS is a **personal AI operating system**. It runs on your hardware, speaks through your channels, remembers your context, and works autonomously on your behalf. It's not a chatbot wrapper. It's a full runtime with memory, a heartbeat, contemplation, tools, and a visual workflow engine.

**Core** is the free, open-source foundation. Everything a single user or small team needs to run a personal AI agent that actually does things.

---

### What's in Core

| System | What It Does |
|--------|-------------|
| **Memory** | SQLite + pgvector hybrid search, auto-capture, entity tracking, embeddings |
| **Heartbeat** | Periodic accountability, contract/promise system, scoring |
| **Contemplation** | Always-on thinking loop -- local Qwen via Ollama, episode journaling |
| **Channels** | Telegram, Discord, Slack, WhatsApp, and more |
| **Workflows** | Visual multi-agent pipeline builder with 62 connector integrations |
| **Dashboard** | React + WebGL avatar, chat, task board, alignment docs editor |
| **30+ Connectors** | Real Python CLI harnesses with tests -- not stubs, not mocks |
| **Intent System** | Three-tier hierarchical policy engine for safe agent behavior |
| **Model Router** | Complexity scoring -- routes to local, fast, balanced, or powerful tier |
| **SIS** | Self-improving system -- lesson extraction from experience |
| **Knowledge Library** | RAG with agent-level ACL, PDF/DOCX/XLSX ingestion |
| **Encrypted Secrets** | AES-256-GCM credential storage with OS keychain integration |

### Install

```bash
curl -fsSL https://argentos.ai/install.sh | bash
```

macOS first. Linux support coming. The installer handles everything -- Node, pnpm, PostgreSQL, Redis, the native Argent.app, and onboarding.

### Contributing to Core

We want Core to be community-driven. Here's how to help:

1. **Star the Core repo** -- seriously, it matters more than you think
2. **Join [Discord](https://discord.gg/argentos)** -- this is where the community lives
3. **File issues** -- bugs, feature requests, questions -- all welcome
4. **Submit PRs** -- we review everything and good contributions ship fast
5. **Build connectors** -- the pattern is documented, each one helps the whole ecosystem
6. **Share what you build** -- your agents, workflows, and use cases inspire others

TypeScript (ESM), strict typing, Oxlint + Oxfmt. Fork, branch, PR, review. See `CONTRIBUTING.md` in Core for details.
